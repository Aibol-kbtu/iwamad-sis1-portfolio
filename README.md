## About the site

This is my personal portfolio for the IWaMAD course. It has three sections: About Me, My path with a table of my weekly results, and a Contact form. There is also a button in the header that switches between light and dark theme.

## Design decisions

1. ## Colours in CSS variables.
 I keep all colours in variables, so the dark theme only changes their values and I don't repeat any styles. The chosen theme is saved in the browser, so it stays after a reload.
2. ## Small set of sizes.
I use only four font sizes and spacing in steps of 8px. This keeps the page looking even and makes it easy to change something in one place.
3. ## Simple navigation.
I left About me, Projects and Contact as plain links in a row. The page is short, so I didn't want extra buttons or effects to distract from the content.
